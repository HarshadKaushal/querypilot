# AI review: fix the first CI run on GitHub

Date: 2026-10-20
Base commit: `324679c` (refactor(core): split history, proposal cache, usage, and audit storage into two files)

## What changed

The repository was pushed to GitHub for the first time (`HarshadKaushal/querypilot`), and the first runs failed in three places. All the tests themselves passed. The failures came from setup.

1. **`integration` job: `Cannot find module '@ayd/shared'` while building `@ayd/core`.** The root `test:int` and `test:e2e` scripts built every package `core` needs except `@ayd/shared`. `test:unit` and `build` already started with it. Locally an old `packages/shared/dist` hid the gap, but CI starts with no `dist`. Both scripts now build `@ayd/shared` first.
2. **`unit` job: sql-guard function coverage 98.83%, below its 100% threshold.** `index.ts` has no logic, but TypeScript compiles each `export { X } from` into a small getter function. No test read `ALLOWED_FUNCTIONS` through `./index`, so its getter never ran. A new test in `guard.spec.ts` ("package") checks that `ALLOWED_FUNCTIONS` is the same set the guard checks against (`FUNCTIONS` in `allowlists.ts`), which is what the model prompt in `@ayd/core` relies on. This closes the loose end recorded on 2026-10-16.
3. **Dependabot: "No Dockerfiles nor Kubernetes YAML found in /".** `.github/dependabot.yml` had a second `docker` entry for `/`, where there is no Dockerfile. It was removed. The entry for `/infra/docker` stays.

Docs: `testing.md` (CI runs on a clean machine, so each test script must build its packages, and what Dependabot checks), `implementation.md` (the sql-guard thresholds, which listed two of the four), and `CONTEXT.md`.

## AI usage

An AI assistant (Claude Code) read the failed run logs with `gh run view --log-failed`, compared the root scripts to find the missing build step, ran sql-guard's coverage report to find the uncovered getter in `index.ts`, and wrote the changes. The user asked for the fixes.

## Suggestions accepted

- **Cover the export with a test instead of excluding `index.ts` from coverage.** The export is used by the prompt, and an exclusion would also hide any real code added to `index.ts` later.
- **Add `@ayd/shared` to the existing script lists**, the smallest change, matching `test:unit`.

## Suggestions rejected

- **Adding a Dependabot `docker-compose` entry** to replace the removed one, so the images in `docker-compose.yml` get updates. Not done here: it adds a new kind of update, and the option should be checked against GitHub's documentation first.
- **Lowering sql-guard's function threshold.** It is safety code, and the blueprint asks for near-complete coverage.

## Decisions

- The user chose to push to a public repository and asked for these fixes (2026-10-20).
