# Accepted dependency advisories

`npm audit` findings that are known and deliberately left in place. Each one says why it is safe here and when to look again. Re-run `npm audit` before a release and whenever Sequelize or Jest is upgraded.

| Package              | Severity                                                 | Pulled in by                                                                                             | Why it is accepted                                                                                                                                                                                                                                                             | Revisit when                                                                                  |
| -------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| `uuid` < 11.1.1      | Moderate (missing buffer bounds check in v3, v5, and v6) | `sequelize` 6 depends on `uuid` 8 (also reported through `sequelize-typescript` and `@nestjs/sequelize`) | The bug is only in `v3`, `v5`, and `v6` when the caller passes its own buffer. Sequelize 6.37.8 calls only `v1` and `v4`, without a buffer (`lib/utils.js`, `lib/dialects/abstract/query-generator.js`). Our models use no UUID defaults; ids come from Node's `randomUUID()`. | A Sequelize 6 release depends on `uuid` 11.1.1 or later, or the project moves to Sequelize 7. |
| `sprintf-js` ≤ 1.1.3 | Moderate (CPU and memory on a huge precision specifier)  | Jest coverage: `babel-plugin-istanbul` → `@istanbuljs/load-nyc-config` → `js-yaml` 3 → `argparse` 1      | Runs only during tests and reads only our own config files. No fixed version of `sprintf-js` exists.                                                                                                                                                                           | Jest's coverage tooling drops `js-yaml` 3, or a fixed `sprintf-js` is published.              |

`sprintf-js` accepted on 2026-10-12; `uuid` on 2026-10-16, with the move to Sequelize (ADR 0015). Every other advisory npm lists (24 moderate in all on 2026-10-16) is one of these two, reported again through each package that depends on it. The move removed the Prisma CLI, and with it the two high advisories accepted on 2026-10-12 (`deepmerge-ts` < 8 and `mysql2` ≤ 3.23.0, both only in Prisma's tooling).

## Fixes tried and not used

- `npm audit fix` changed only `babel-plugin-istanbul` and cleared nothing.
- `npm audit fix --force` would downgrade Jest (to 25), ts-jest (to 27), and `sequelize-typescript` (to 0.6). Not used.
